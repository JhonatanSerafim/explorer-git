# Explorer Git

Um projeto React moderno construído com TypeScript e Tailwind CSS, utilizando Vite como bundler.

## 🚀 Tecnologias Utilizadas

- **React 18** - Biblioteca para interfaces de usuário
- **TypeScript** - Superset tipado do JavaScript
- **Tailwind CSS** - Framework CSS utilitário
- **Vite** - Build tool e dev server ultra-rápido
- **ESLint** - Linter para qualidade de código

## 📦 Instalação

1. Clone o repositório:
```bash
git clone <url-do-repositorio>
cd explorer-git
```

2. Instale as dependências:
```bash
npm install
```

## 🛠️ Scripts Disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Cria a build de produção
- `npm run preview` - Visualiza a build de produção
- `npm run lint` - Executa o linter ESLint

## 🎨 Funcionalidades

- ✅ Configuração completa do TypeScript
- ✅ Tailwind CSS configurado e funcionando
- ✅ Componente de exemplo com design responsivo
- ✅ Contador interativo demonstrando React hooks
- ✅ Design moderno e responsivo
- ✅ ESLint configurado para qualidade de código

## 🚀 Como Executar

Execute o comando para iniciar o servidor de desenvolvimento:

```bash
npm run dev
```

O projeto estará disponível em `http://localhost:5173`

## 📁 Estrutura do Projeto

explorer-git/
